# Installation

ucharm is available as a single binary for macOS and Linux.

## Rust release candidate

The current Rust implementation is available as `v0.6.0-rc.1`. Download the
CLI for your operating system and CPU architecture:

```bash
# Linux (x86_64)
curl -L https://github.com/ucharmdev/ucharm/releases/download/v0.6.0-rc.1/ucharm-linux-x86_64 -o ucharm
chmod +x ucharm
sudo mv ucharm /usr/local/bin/

# Linux (ARM64)
curl -L https://github.com/ucharmdev/ucharm/releases/download/v0.6.0-rc.1/ucharm-linux-aarch64 -o ucharm
chmod +x ucharm
sudo mv ucharm /usr/local/bin/

# macOS (Apple Silicon)
curl -L https://github.com/ucharmdev/ucharm/releases/download/v0.6.0-rc.1/ucharm-macos-aarch64 -o ucharm
chmod +x ucharm
sudo mv ucharm /usr/local/bin/

# macOS (Intel)
curl -L https://github.com/ucharmdev/ucharm/releases/download/v0.6.0-rc.1/ucharm-macos-x86_64 -o ucharm
chmod +x ucharm
sudo mv ucharm /usr/local/bin/
```

Every release also includes a `.sha256` file for verification. There is no
architecture-independent CLI: choose the asset that matches the machine where
the CLI itself will run. `ucharm build --targets` lists the four application
targets it can produce.

## Homebrew stable

Homebrew remains on the previous stable release while the Rust release is an
RC. It will move to Rust when 0.6 is promoted:

```bash
brew install ucharmdev/tap/ucharm
```

## Verify Installation

```bash
ucharm --version
```

You should see output like:

```
μcharm v0.6.0-rc.1
```

## Editor Setup

For the best development experience, run `ucharm init` in your project directory:

```bash
mkdir my-cli && cd my-cli
ucharm init
```

This creates:
- **Type stubs** for IDE autocomplete
- **AI instructions** for Claude Code, Cursor, Copilot, etc.
