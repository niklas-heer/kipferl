# Installation

kipferl is available as a single binary for macOS and Linux.

## Homebrew

Install the stable release on macOS or Linux:

```bash
brew install niklas-heer/tap/kipferl
```

Existing Kipferl users can update with `brew upgrade kipferl`.

If the old μcharm 0.5 Homebrew formula is installed, replace it once. Kipferl
0.6 keeps the old command as a deprecated alias, so existing scripts continue
to work during the transition:

```bash
brew uninstall --force ucharm
brew install niklas-heer/tap/kipferl
```

## Direct download

Kipferl `v0.6.0` is available for four native targets. Download the CLI for
your operating system and CPU architecture:

```bash
# Linux (x86_64)
curl -L https://github.com/niklas-heer/kipferl/releases/download/v0.6.0/kipferl-linux-x86_64 -o kipferl
chmod +x kipferl
sudo mv kipferl /usr/local/bin/

# Linux (ARM64)
curl -L https://github.com/niklas-heer/kipferl/releases/download/v0.6.0/kipferl-linux-aarch64 -o kipferl
chmod +x kipferl
sudo mv kipferl /usr/local/bin/

# macOS (Apple Silicon)
curl -L https://github.com/niklas-heer/kipferl/releases/download/v0.6.0/kipferl-macos-aarch64 -o kipferl
chmod +x kipferl
sudo mv kipferl /usr/local/bin/

# macOS (Intel)
curl -L https://github.com/niklas-heer/kipferl/releases/download/v0.6.0/kipferl-macos-x86_64 -o kipferl
chmod +x kipferl
sudo mv kipferl /usr/local/bin/
```

Every release also includes a `.sha256` file for verification. Download it
next to the binary and run:

```bash
# macOS
shasum -a 256 -c kipferl-macos-aarch64.sha256

# Linux
sha256sum -c kipferl-linux-x86_64.sha256
```

Adjust the filename for your selected target. There is no
architecture-independent CLI: choose the asset that matches the machine where
the CLI itself will run. `kipferl build --targets` lists the four application
targets it can produce.

Kipferl 0.6 also installs `ucharm` as a deprecated alias for one release cycle.

## Verify Installation

```bash
kipferl --version
```

You should see output like:

```
Kipferl v0.6.0
```

## Editor Setup

For the best development experience, run `kipferl init` in your project directory:

```bash
mkdir my-cli && cd my-cli
kipferl init
```

This creates:
- **Type stubs** for IDE autocomplete
- **AI instructions** for Claude Code, Cursor, Copilot, etc.
