Use [Kipferl 0.7.2](/docs/getting-started/installation#stable-release)
for the project and package workflows below. Start with the [first-app tutorial](/docs/getting-started/quick-start), then
adapt one of these complete scripts to your own work. Every Python recipe below
is copied directly from `examples/recipes/` and checked for drift. CI executes
all four against the runtime using temporary files and a local HTTP server.

- [CSV summaries, API clients, repository inspection, and reports](/docs/guides/recipes)
- [Project defaults, templates, tests, and shell completion](/docs/commands/projects)
- [Local modules, bundled assets, and portable applications](/docs/guides/packaging)
- [PyPI packages and compatibility catalog](/docs/guides/packages)
- [Popular package audit](/docs/guides/package-audit)
- [Debugging and supported dependencies](/docs/guides/troubleshooting)

The recipes use the built-in modules only. They do not need pip, credentials,
or external services to run their checks.

For work on the Rust runtime, CLI, or website, use the
[contributor setup and validation guide](/docs/guides/development).
